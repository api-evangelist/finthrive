# FinThrive

> FinThrive is a US healthcare revenue cycle management (RCM) technology company serving
> hospitals, health systems, ambulatory and physician practices, payers, life sciences
> organizations and channel partners. It sells a SaaS platform covering patient access,
> revenue integrity, revenue optimization, analytics, education and agentic AI automation,
> built on FinThrive Fusion, its unified data-intelligence and integration layer. FinThrive
> operates a production API but does not publish a machine-readable contract: the developer
> portal is reachable, and the API catalog behind it is not.

Generated by API Evangelist because FinThrive does not serve an llms.txt of its own
(https://finthrive.com/llms.txt returns HTTP 404). Everything below was fetched from
public URLs with no credentials.

## API surface

- [FinThrive API developer portal](https://api-portal.nthrive.com/): Microsoft Azure API
  Management developer portal. Publicly reachable. Advertises auto-generated API
  documentation, multi-language code samples, an interactive API Console and a document
  library — none of which are visible without signing in. The portal's own catalog
  endpoint, `/mapi/apis?api-version=2022-08-01`, returns `{"value":[],"count":0}` to an
  anonymous caller, as does `/mapi/products`.
- [API gateway](https://api.finthrive.com): live Azure API Management gateway. Answers
  unmatched paths with `{"statusCode": 404, "message": "Resource not found"}`. Aliased as
  `https://api.nthrive.com` — both hostnames report the same Azure Application Insights
  instrumentation key, so they front one production instance.
- [Portal sign in](https://api-portal.nthrive.com/signin): Azure Active Directory.
- Evaluation sign in: `https://api-portal.nthrive.com/evalsignin`, for developers issued
  credentials directly by FinThrive.

No OpenAPI, Swagger, GraphQL, AsyncAPI, MCP or A2A agent card is published on any
FinThrive host. See `well-known/finthrive-well-known.yml` for the full 36-path probe.
